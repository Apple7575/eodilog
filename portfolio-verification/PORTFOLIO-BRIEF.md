# 어디로그 · 포트폴리오 작성 브리프

대표 사례는 **온디바이스 한국어 여행 사진 검색**이다. 여행 앨범에서 한국어로 사진을 찾도록 이미지·텍스트 임베딩을 기기에서 계산하고, 사진 벡터를 재사용한다. 공개 소스는 [어디로그 GitHub](https://github.com/Apple7575/eodilog)에서 확인할 수 있다.

## 개인 기여와 기술 근거

장수철이 SigLIP2 증류·양자화 스크립트와 모바일 모델 리포트를 작성하고(`03277461`), Android ONNX 검색과 기기 사진 인덱싱을 구현했다(`ae314b33`). 기기 분류 결과를 받는 API(`09174325`)와 모델 버전별 임베딩 캐시 및 모델 파일 검증(`af7ebff0`)도 담당했다. 번호는 팀 저장소의 커밋이다. 실기기 후속 검증에서는 기존 캐시 효과를 측정하고, `groupSimilar`에서 동일 임베딩 쌍의 유사도 판정을 재사용하도록 개선했다. 이 후속 변경은 로컬 작업본 기준이다.

## 인용할 수치

| 근거 | 수치와 조건 |
| --- | --- |
| Galaxy S22 · Android 16 개발 빌드 | 합성 사진 990장, 정리 버튼 → 검색 준비 **319.02초 → 20.65초**. 앱 프로세스 종료 후 재진입에서 신규 인코딩 0장, 990장 재사용. 조건별 1회. |
| 같은 실기기 · 사진 10장 추가 | 기존 990장 재사용, 신규 10장만 인코딩. 총 1,000장 검색에서 새 카드키 사진 1위. |
| 같은 실기기 · 묶기 최적화 | 반복 합성 사진 1,000장에서 **묶기 단계 13.27초 → 0.23초**. 카드키 검색 60개 결과의 순서와 점수가 일치. 반복 사진이 드문 실제 앨범의 개선 폭은 미측정. |
| 기존 모델 리포트 | 약 **4.3GB 교사 모델 → 배포 ONNX 두 파일 191 MiB**. 교사·최종 모델의 검색 Top-5는 각각 **78.5%**. [리포트](https://github.com/Apple7575/eodilog/blob/592d2351/ai/docs/reports/ondevice-photo-ai.md) |
| Windows CPU 재현 | 같은 한국어 질의 1,931개에서 학습 전 B-32 대비 **Top-1 27.3% → 47.4%**. |

귀속과 한계. Galaxy S22에서 A/B 검색 ‘비빔밥’의 19개 결과 순서·점수가 일치했다. 모델과 여행 기간을 준비한 열린 화면에서 비행기 모드·Wi-Fi OFF로 검색을 확인했다. 서버 인증을 포함한 오프라인 시작은 미검증이다. 앱 후보 상한은 1,000장이다. 영상과 캡처는 별도로 선정한 ‘단풍’ 시연이다. Galaxy S22에서 합성 사진 1,000장을 대상으로 검색했고, 단풍 든 산길 사진 1장만 결과로 표시됐다. 검색 품질 전체를 대표하는 평가로 사용하지 않는다.

## 작성 요청

> 이 브리프, 실기기 CSV, 영상, 캡처로 AI 응용 개발자 포트폴리오 한 페이지를 작성해줘. 사용자 문제, 내 기여, 구현, 실기기에서 발견한 병목과 개선, 평가 한계 순으로 구성해줘. 기존 임베딩 캐시 효과와 후속 묶기 최적화를 각각 귀속하고, Android 지연·Windows CPU 검색 품질·모델 리포트 수치에 환경과 규모를 명시해줘. How + Result 제목, 이력서용 두 문장, 본문, 영상·캡처 캡션을 작성해줘.
